# David — Default Profile

## User Profile

- **Vocal range**: E3–B3 (comfortable baritone/tenor), i.e. MIDI pitch 64–71
- **Reference key**: C#m (preferred), Em (secondary)
- **Singing style**: spoken-sung, nonchalant & cynical (influences Gainsbourg / Despropes)
- **Language**: French unless asked otherwise
- **Reference analysis** (from `data/tests/01- Masculiniste-Emotionnal-Indie-Rock.mp3`):
  - Spectral centroid: 645 Hz (warm, low timbre)
  - Dynamic range: 81.2 dB (expressive voice)
  - Tuning offset: -0.05 cents (in-tune)

## Production Constraints

- Max 8 tracks (Ableton Live Lite), max 16 scenes per track
- **Start with native Ableton plugins** (Analog, Drift, Wavetable, Electric, Simpler, native effects) to structure the song, then configure Surge XT via OSC after activating it
- Prefer a **Drumkit** (pre-configured `.adg`) rather than building a Drum Rack from scratch
- Short structure preferred (~1m30-2m)
- Style: organic pop — warm timbres, natural drums, no EDM

## References

Pink Floyd, Morcheeba, Prince, Deep Purple, Ben Harper, French indie rock, Gainsbourg, analog pop

## Native FX Chains

- **Drums**: Drum Buss → Compressor → Reverb (send)
- **Bass**: Amp → Compressor → Saturator
- **Piano/Keys**: Reverb → Chorus → Compressor
- **Pad**: Reverb → Auto Filter → Delay
- **Lead**: Delay → Reverb → Auto Filter
- **Vocals**: EQ Eight → Compressor → Reverb → Delay
- **Percs**: Reverb (send) → Saturator
- **FX**: Reverb → Delay → Grain Delay → Auto Filter
