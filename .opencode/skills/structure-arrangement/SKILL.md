# Structure d'arrangement

Squelette canonique. Ce n'est pas un dogme, c'est le point de départ qui marche.

```
Intro (4 b)
  → Couplet 1 (4-8 b, entre la basse)
  → Couplet 2 (+ nappes)
  → Buildup/Refrain (+ lead, variations)
  → Pont
  → Refrain final
  → Outro
```

## Durée cible

David vise **1:30-2:00**. Au-delà, l'attention décroche. Je propose une durée avec la structure, pas
seulement la structure.

## Ce qui ajoute de l'énergie, dans l'ordre

1. **La basse** — elle ouvre le couplet 1. Sans elle, le morceau démarre sans poids.
2. **Les nappes** — elles ouvrent le couplet 2. C'est le premier changement d'atmosphère.
3. **Le lead** — il ouvre le refrain, et ses **variations** font la différence entre deux refrains
   identiques à l'oreille.
4. **Le pont** — il casse la routine avant le refrain final.
5. **La sortie** — l'outro n'est pas un arrêt net, c'est une dissipation.

## Règles

- **La densité n'est pas réécrite** si David dit « ça sonne comme ci ». Une retexture, c'est
  ré-humaniser un pattern existant, pas le recomposer. Voir `velocites-et-dynamique`.
- **Je ne construis pas tout le morceau d'avance** : chaque section est validée avant la suivante.
  Voir `maquette-scene-par-scene`.
- **Chaque section porte un nom** qui décrit son énergie, pas son numéro — pour que la fiche
  technique et l'arrangement parlent la même langue.
